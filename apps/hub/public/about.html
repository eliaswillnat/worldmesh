About WorldMesh

An open network of 3D worlds

WorldMesh connects independently hosted 3D worlds across the web.

Creators build and host their worlds wherever they want. WorldMesh connects them through a shared discovery and navigation layer, making it easier for people to move from one world to another.

The worlds remain independent. WorldMesh does not need to own or host them.

Mission

Make the open web feel like one connected 3D space.

WorldMesh aims to give creators a common way to publish, discover and connect interactive 3D experiences without requiring them to build on a single centralized platform.

Vision

Today, 3D experiences on the web are usually isolated websites.

WorldMesh imagines something different: thousands of independently created worlds connected through common standards, where users can discover a world, enter it, explore it and continue directly into another.

A web of worlds instead of one metaverse.

How it works

Creators host their own worlds.

WorldMesh provides the layer connecting them:

  • discovery
  • portals between worlds
  • common movement and camera conventions
  • optional shared identity
  • multiplayer presence
  • compatibility tools for creators

A world can exist completely independently from WorldMesh. Connecting it simply makes it part of the wider network.

Independent by design

WorldMesh is not a hosting platform for 3D worlds.

Creators keep control over their:

  • hosting
  • code
  • assets
  • design
  • gameplay
  • monetization
  • infrastructure

WorldMesh is the connective layer between them.

Built for creators

Adding a world should be simple.

A creator can build with Three.js, WebGL, an engine, AI tools or any other technology capable of running on the web.

WorldMesh does not dictate what a world should look like or what it should be used for.

Games, social spaces, experiments, virtual environments, portfolios and completely new types of experiences can all exist on the same network.

A common way to explore

Different worlds can look completely different while still feeling familiar to navigate.

WorldMesh is developing shared conventions for movement, cameras, interaction, portals and other basic systems so users do not have to relearn everything each time they enter a new world.

An open network

The long-term goal is not to create one giant centrally controlled virtual world.

It is to connect many independent ones.

Just as the web connects independently hosted websites, WorldMesh aims to connect independently hosted 3D spaces.

Community

WorldMesh grows through the creators building worlds and the people exploring them.

Anyone can submit a world and help expand the network.

Open source

WorldMesh is being developed openly.

Its compatibility tools, shared runtime and technical documentation are available through the WorldMesh GitHub repository.

Created by Elias Willnat

WorldMesh began in 2026 as an experiment around a simple question:

What if 3D worlds on the web could connect to each other instead of existing as isolated experiences?

That experiment became WorldMesh.
